    Network Vulnerability Scanner

    scanner.py

    Nmap-powered scan (nmap -sV) with service and version detection, plus an offline known-risk lookup — flags services like exposed Redis or legacy SMB against their known exploit history. Falls back to a built-in multi-threaded TCP scan if Nmap isn’t installed.

    Packet Sniffer & Traffic Analyzer

    sniffer.py

    Live capture through tshark (Wireshark’s capture engine, with a Scapy fallback) and a protocol breakdown, plus heuristic anomaly detection: ARP spoofing (one IP, multiple MACs), SYN floods (sliding time-window rate), and port-scan behavior (one source touching many destination ports).

    why this can't run on a website

    Raw packet capture and arbitrary port scanning require OS-level network access that browsers deliberately withhold from every website — this is a security boundary, not a missing feature. It's the same reason Wireshark and nmap don't have "run in browser" versions. Download the toolkit below to run these two modules for real.

    Run it locally

    Docker · one command

    Clone, set a password, run one Docker command — works on Windows, macOS, and Linux.

    01
    Clone the repo
    git clone https://github.com/avinash09-cmd/cybersec-guard-fullstack.git
cd cybersec-guard-fullstack
    02
    Set a database password
    Copy the example env file and choose a strong MySQL password (avoid @ / : in it).
    cp .env.example .env
# edit .env and set MYSQL_ROOT_PASSWORD
    03
    Start everything with Docker
    One command builds the app and starts MySQL, with Nmap and tshark already installed in the image. Then open http://localhost:5000.
    docker compose up --build
